# Script to add Italic font family to Cyrillic alphabet in Shobhika font

Usage:

```shell
python build_shobhika_family.py \
  --shobhika-reg ~/Downloads/Shobhika-Regular.ttf \
  --shobhika-bold ~/Downloads/Shobhika-Bold.ttf \
  --pt-italic ~/Downloads/PTSerif-Italic.ttf \
  --pt-bolditalic ~/Downloads/PTSerif-BoldItalic.ttf \
  -o ./my_book_fonts
```
